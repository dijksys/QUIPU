# QUIPU 1.0.0

## Presentación

QUIPU es una aplicación Android nativa para gestionar notas personales y
recordatorios. Está diseñada para funcionar completamente sin conexión, con
almacenamiento local y una interfaz minimalista en español.

Esta es la primera versión estable distribuida públicamente.

## Funcionalidades

### Notas

- Crear, editar y eliminar notas.
- Guardado automático con debounce y volcado al salir del editor.
- Fijar y desfijar notas.
- Archivar y desarchivar.
- Papelera con restauración y eliminación definitiva.
- Búsqueda por título y contenido.
- Fechas de creación y última modificación.

### Recordatorios

- Título, descripción opcional, fecha y hora.
- Vinculación opcional a una nota.
- Estados pendiente, vencido, completado y cancelado.
- Notificaciones locales.
- Alarmas exactas cuando el sistema lo permite; programación aproximada como
  alternativa explicada al usuario.
- Reprogramación tras reiniciar el dispositivo, cambiar la hora/zona horaria o
  actualizar la aplicación.
- Apertura del recordatorio al pulsar la notificación.

### Interfaz y ajustes

- Pantallas de Inicio, Notas, Editor, Recordatorios, Editor de recordatorios y
  Ajustes.
- Icono oficial de QUIPU adaptativo, redondeado y monocromático.
- Tema claro, oscuro y automático.
- Activación global de notificaciones.
- Estados vacíos, snackbars y confirmaciones para acciones destructivas.

## Cambios de esta versión

- Primera versión estable `1.0.0`.
- Identificador definitivo de la aplicación: `io.github.dijksys.quipu`.
- Migración completa de paquetes Kotlin al nuevo identificador.
- Firma de distribución configurada para futuras actualizaciones.
- Icono oficial de QUIPU integrado en todas las densidades y variantes.
- Esquema Room exportado bajo el nuevo paquete, conservando los esquemas
  históricos y la versión de base de datos existente.

## Compatibilidad

- Android mínimo: 8.0 (API 26).
- `compileSdk`: 37.
- `targetSdk`: 37.
- Arquitectura: APK universal para Android.
- No requiere conexión a Internet para funcionar.

## Instalación

1. Descarga `QUIPU-1.0.0.apk` desde la release oficial.
2. Verifica el archivo con `SHA256SUMS.txt`.
3. Autoriza la instalación desde orígenes desconocidos si Android lo solicita.
4. Instala el APK.

También se puede instalar mediante ADB:

```powershell
adb install QUIPU-1.0.0.apk
```

### Identidad y datos

La versión con identificador `io.github.dijksys.quipu` es una identidad nueva de
aplicación. No se migran automáticamente los datos de instalaciones anteriores
con identificador `com.example.quipu`. Ambas identidades pueden coexistir en el
dispositivo sin compartir base de datos ni preferencias.

## Privacidad

- No hay cuentas de usuario.
- No se envía información a servidores.
- No se utiliza conexión a Internet.
- Notas, recordatorios y preferencias permanecen en el almacenamiento local del
  dispositivo.

## Limitaciones conocidas

- Los recordatorios no admiten recurrencia.
- No existe sincronización entre dispositivos ni copia de seguridad en la nube.
- La interfaz está disponible en español.
- La búsqueda utiliza coincidencia de texto; no hay índice FTS.
- Las alarmas exactas dependen del permiso del sistema y del fabricante. Sin ese
  permiso, Android puede retrasar los avisos.
- Las notas eliminadas definitivamente conservan sus recordatorios, pero los
  desvinculan.
- El icono de notificaciones es independiente del icono del launcher.
