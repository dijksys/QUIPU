# QUIPU 2.1.3

## Presentación

QUIPU 2.1.3 es una actualización de estabilización centrada en dos defectos
críticos: la interacción de las casillas Markdown y el bloqueo al vaciar la
papelera. Mantiene la búsqueda FTS4, las etiquetas, el editor enriquecido y el
funcionamiento completamente local.

## Defectos corregidos

### Casillas Markdown

Las casillas `☐` y `☑` ahora responden directamente en el editor:

- Un toque corto alterna el estado.
- El cambio modifica `[ ]` / `[x]` en el Markdown original.
- La vista se actualiza inmediatamente.
- El autoguardado de 600 ms se activa sin crear otro sistema de guardado.
- El estado se conserva al cerrar y reabrir la nota.
- La pulsación larga y la selección de texto no alteran la casilla.

### ANR al vaciar la papelera

La causa era una recursión infinita en `NotesViewModel.emptyTrash()`: el método
miembro y la dependencia `EmptyTrashUseCase` compartían nombre. Cada llamada
lanzaba otra corrutina hasta agotar el heap, bloquear el hilo principal y
provocar `OutOfMemoryError` y ANR.

La corrección:

- Ejecuta el caso de uso real.
- Impide ejecuciones simultáneas.
- Deshabilita el botón durante el vaciado.
- Muestra progreso.
- Mantiene la transacción y la integridad de notas, FTS, etiquetas y
  recordatorios.

## Compatibilidad

- Application ID: `io.github.dijksys.quipu`
- Versión: `2.1.3`
- versionCode: `7`
- Android mínimo: 8.0 (API 26)
- compileSdk: 37
- targetSdk: 37
- Arquitectura: APK universal
- Actualización compatible con QUIPU 2.0.1: misma identidad y firma.

La actualización conserva notas, etiquetas, recordatorios, preferencias, tema y
estado del onboarding. La base de datos sigue en versión 2; no se añadieron
migraciones nuevas.

## Instalación

1. Descargar `QUIPU-2.1.3.apk`.
2. Instalar sobre la versión anterior para conservar los datos.
3. Abrir QUIPU y comprobar notas, casillas y papelera.

```powershell
adb install -r "QUIPU-2.1.3.apk"
```

## Limitaciones conocidas

- FTS4 no ofrece BM25; la relevancia usa prioridades deterministas.
- No hay búsqueda difusa ni subcadenas internas.
- El editor no admite HTML, tablas, imágenes ni listas anidadas.
- El formato visual oculta delimitadores; editar en sus bordes requiere
  precisión.
- Los dominios sin esquema se abren siempre como HTTPS.
- La interfaz está en español.
