# QUIPU 1.0.3

## Presentación

QUIPU 1.0.3 es una actualización estable de la aplicación Android para gestionar
notas y recordatorios sin conexión. Mantiene el almacenamiento local, la
interfaz en español y la compatibilidad de actualización con QUIPU 1.0.0.

Esta versión mejora la presentación del encabezado de Inicio, añade enlaces al
proyecto dentro de Ajustes y refina el editor de notas para comunicar con
claridad el estado de guardado.

## Cambios de la versión

- Nuevo estado de guardado explícito en el editor: vacío, cambios sin guardar,
  guardando, guardado y error.
- Acción «Reintentar» cuando falla una escritura, conservando el borrador.
- Salir, pasar a segundo plano o reabrir una nota sin cambios ya no modifica
  `updatedAt`.
- Las ediciones realizadas durante un guardado activo se conservan como
  pendientes y se guardan después.
- Indicadores «Nota creada» y «Todos los cambios guardados», junto con los
  metadatos «Creada el» y «Última actualización».
- La sesión «Nueva nota» se mantiene estable después del primer autoguardado.

## Mejoras de interfaz

- El encabezado de Inicio ahora presenta tres niveles: fecha como etiqueta
  secundaria, «Organiza tu día.» como título principal y la descripción de la
  aplicación como texto de apoyo.
- La navegación inferior adopta una presentación de cápsula flotante.
- El editor separa el título contextual del estado de persistencia y muestra
  este último en un footer discreto y accesible.
- Los enlaces del proyecto se integran en la tarjeta Acerca de, con indicador de
  enlace externo, colores del tema y soporte para modo claro y oscuro.

## Compatibilidad

- Android mínimo: 8.0 (API 26).
- `compileSdk`: 37.
- `targetSdk`: 37.
- Arquitectura: APK universal para Android.
- No requiere conexión a Internet para las funciones de la aplicación.
- Actualización compatible con QUIPU 1.0.0: mismo identificador y misma firma.
- Los datos locales de notas, recordatorios y preferencias se conservan al
  actualizar.

## Identificador de aplicación

`io.github.dijksys.quipu`

No se ha realizado ninguna migración de identificador en esta versión.

## Instalación

1. Descarga `QUIPU-1.0.3.apk` desde la release oficial.
2. Verifica el archivo con `SHA256SUMS.txt`.
3. Autoriza la instalación desde orígenes desconocidos si Android lo solicita.
4. Instala el APK sobre una versión anterior compatible.

También se puede actualizar mediante ADB:

```powershell
adb install -r QUIPU-1.0.3.apk
```

No es necesario desinstalar QUIPU 1.0.0 ni borrar sus datos.

## Limitaciones conocidas

- Los recordatorios no admiten recurrencia.
- No existe sincronización entre dispositivos ni copia de seguridad en la nube.
- La interfaz está disponible en español.
- La búsqueda utiliza coincidencia de texto; no hay índice FTS.
- Las alarmas exactas dependen del permiso del sistema y del fabricante. Sin ese
  permiso, Android puede retrasar los avisos.
- Las notas eliminadas definitivamente conservan sus recordatorios, pero los
  desvinculan.
