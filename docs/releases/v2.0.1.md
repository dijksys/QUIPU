# QUIPU 2.0.1

## Presentación

QUIPU 2.0.1 es la primera versión estable que reúne la búsqueda indexada, el
sistema de etiquetas y el editor Markdown enriquecido. Mantiene el
funcionamiento completamente local, sin cuentas, servidores ni conexión
obligatoria.

Esta versión consolida el trabajo que aparecía en `Unreleased` y no introduce
cambios de identidad Android.

## Novedades

- Búsqueda FTS4 con tokenizador `unicode61` y eliminación de diacríticos.
- Búsqueda por título, contenido Markdown y etiquetas.
- Prefijos, varias palabras y búsqueda sin distinguir tildes o mayúsculas.
- Filtros por estado y fecha, incluido rango personalizado.
- Ordenación por relevancia, fecha o título.
- Resaltado de coincidencias en título, extracto y etiquetas.
- Buscador prominente en Inicio que abre Notas con la consulta conservada.

## Mejoras

- Editor Markdown con formato visual en tiempo real.
- Una sola superficie de edición, sin selector Editar/Vista previa.
- Toolbar contextual acoplada al teclado y visible solo con el contenido
  enfocado.
- Corrección del reinicio de Gboard al aplicar encabezados.
- Detección automática de URLs con y sin esquema.
- Validación de dominios, puertos, IDN y sufijos superiores.
- Apertura de enlaces HTTP/HTTPS en el navegador externo.
- Conservación del cursor, la selección y el autoguardado.
- Extractos limpios para las tarjetas de notas.

## Compatibilidad

- **Application ID:** `io.github.dijksys.quipu`
- **Versión:** `2.0.1`
- **versionCode:** `6`
- **Android mínimo:** 8.0 (API 26)
- **compileSdk:** 37
- **targetSdk:** 37
- **Arquitectura:** APK universal para Android

La actualización conserva notas, etiquetas, recordatorios, preferencias, tema y
estado del onboarding. La firma es la misma que en las versiones estables
anteriores.

## Migración de Room

La base de datos pasa de la versión 1 a la versión 2 mediante
`MIGRATION_1_2`. La migración crea las tablas de etiquetas, relaciones e índice
FTS4, y rellena el índice con las notas existentes.

No se usa `fallbackToDestructiveMigration()`. Las notas y sus metadatos se
conservan.

## Instalación

1. Descargar `QUIPU-2.0.1.apk` desde la release.
2. Permitir la instalación de aplicaciones de origen desconocido si el sistema
   lo solicita.
3. Instalar sobre una versión anterior para conservar los datos.
4. Abrir QUIPU y comprobar que las notas y recordatorios siguen disponibles.

También se puede instalar por ADB:

```powershell
adb install -r "QUIPU-2.0.1.apk"
```

## Limitaciones conocidas

- No hay recurrencia de recordatorios ni sincronización en la nube.
- No hay búsqueda difusa ni subcadenas internas.
- FTS4 no ofrece BM25; la relevancia usa prioridades deterministas.
- El editor no admite HTML, tablas, imágenes ni listas anidadas.
- El formato visual oculta delimitadores; editar justo en sus bordes requiere
  precisión.
- Los dominios sin esquema se abren siempre como HTTPS.
- La interfaz está en español y no se han añadido traducciones.
