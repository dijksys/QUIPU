# QUIPU 1.1.7

## Presentación

QUIPU 1.1.7 es una actualización estable centrada en la claridad visual de
Ajustes y en la integración del nuevo logo oficial. Mantiene las funciones de
notas y recordatorios sin cambios y conserva la compatibilidad con los datos y
las preferencias de versiones anteriores.

## Mejoras visuales

- Selector de apariencia horizontal con tres píldoras: Claro, Oscuro y
  Automático.
- Cada modo utiliza su icono, mantiene el mismo ancho y muestra una selección
  inequívoca con `primaryContainer` y borde `primary`.
- Las opciones de notificaciones se separaron en tres tarjetas independientes.
- La tarjeta de recordatorios activos conserva el interruptor y su lógica de
  cancelación/reprogramación.
- Las tarjetas de permisos muestran insignias de estado y acciones para
  solicitar el permiso o abrir los ajustes del sistema.
- La explicación de las alarmas exactas permanece dentro de su tarjeta, con
  jerarquía secundaria.
- Acerca de y Proyecto se separaron visualmente. Perfil y repositorio tienen
  tarjetas independientes y pulsables.

## Identidad visual

- El logo oficial cuadrado se incorporó como nuevo maestro en
  `assets/branding/quipu.png`.
- Se regeneraron el icono adaptativo, el monocromático y las variantes
  heredadas de launcher.
- La bienvenida y la tarjeta Acerca de utilizan el nuevo recurso
  `quipu_logo.png` con fondo blanco redondeado.
- Se retiró el logo inclinado anterior y sus recursos derivados.
- El icono de notificaciones continúa siendo la campana independiente.

## Compatibilidad

- Android mínimo: 8.0 (API 26).
- `compileSdk`: 37.
- `targetSdk`: 37.
- Arquitectura: APK universal para Android.
- `applicationId`: `io.github.dijksys.quipu`.
- Actualización compatible con QUIPU 1.0.9 y versiones anteriores: mismo
  identificador y misma firma.
- Se conservan notas, recordatorios, preferencias y el estado del onboarding.

## Instalación

1. Descarga `QUIPU-1.1.7.apk` desde la release oficial.
2. Verifica el archivo con `SHA256SUMS.txt`.
3. Autoriza la instalación desde orígenes desconocidos si Android lo solicita.
4. Instala el APK sobre una versión anterior compatible.

También se puede actualizar mediante ADB:

```powershell
adb install -r QUIPU-1.1.7.apk
```

No es necesario desinstalar QUIPU ni borrar sus datos.

## Limitaciones conocidas

- Los recordatorios no admiten recurrencia.
- No existe sincronización entre dispositivos ni copia de seguridad en la nube.
- La interfaz está disponible en español.
- La búsqueda utiliza coincidencia de texto; no hay índice FTS.
- Las alarmas exactas dependen del permiso del sistema y del fabricante. Sin ese
  permiso, Android puede retrasar los avisos.
- Las notas eliminadas definitivamente conservan sus recordatorios, pero los
  desvinculan.
