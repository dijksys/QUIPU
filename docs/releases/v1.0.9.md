# QUIPU 1.0.9

## Presentación

QUIPU 1.0.9 es una actualización estable de la aplicación Android para gestionar
notas y recordatorios sin conexión. Incorpora una pantalla de bienvenida para el
primer inicio de una instalación nueva y mantiene la compatibilidad con los
datos y las preferencias de versiones anteriores.

La bienvenida presenta la identidad de QUIPU y tres funciones reales de la
aplicación: notas, recordatorios y privacidad local. No se presentan tareas,
cuentas ni sincronización porque no forman parte del producto.

## Cambios de la versión

- Nueva pantalla de bienvenida de primer inicio.
- Indicador persistente `onboarding_completed` dentro del DataStore existente.
- Detección de instalaciones anteriores para no repetir la bienvenida a usuarios
  que actualizan desde 1.0.0 o 1.0.3.
- Bloqueo de la navegación principal hasta resolver el estado inicial, evitando
  que Inicio aparezca durante unos instantes antes de la bienvenida.
- Conservación de notificaciones pendientes: un recordatorio abierto desde una
  notificación se muestra después de completar la bienvenida.
- Manejo de errores de lectura o escritura con reintento y sin acceso
  prematuro a Inicio.

## Mejoras de interfaz

- Composición vertical con encabezado de marca, tarjeta informativa, botón
  principal y cierre.
- Encabezado centrado con el símbolo oficial, el wordmark QUIPU y la frase
  «Tu espacio para organizarte».
- Tarjeta redondeada con borde sutil y superficies del tema actual.
- Tres filas de funcionalidades con contenedores de iconos redondeados.
- Botón «Comenzar» de ancho completo, esquinas muy redondeadas y área táctil
  superior a 48 dp.
- Adaptación a temas claro y oscuro, pantallas pequeñas, rotación, escalas de
  texto e insets del sistema.
- Navegación por desplazamiento en el área informativa sin ocultar el botón
  principal.

## Compatibilidad

- Android mínimo: 8.0 (API 26).
- `compileSdk`: 37.
- `targetSdk`: 37.
- Arquitectura: APK universal para Android.
- No requiere conexión a Internet para las funciones de la aplicación.
- Actualización compatible con QUIPU 1.0.0 y 1.0.3: mismo identificador y misma
  firma.
- Los datos locales de notas, recordatorios y preferencias se conservan al
  actualizar.
- Los usuarios existentes no vuelven a ver la bienvenida.

### Detección de primer inicio

La primera vez que se abre una versión con onboarding se comprueba si existen
la base de datos Room `quipu.db`, el archivo de preferencias
`quipu_settings.preferences_pb` o una actualización del paquete según
`PackageManager`. Si hay evidencia de una instalación anterior, la bienvenida se
marca como completada sin mostrarse. La decisión se guarda en DataStore para no
resolverla de nuevo.

## Identificador de aplicación

`io.github.dijksys.quipu`

No se ha realizado ninguna migración de identificador en esta versión.

## Instalación

1. Descarga `QUIPU-1.0.9.apk` desde la release oficial.
2. Verifica el archivo con `SHA256SUMS.txt`.
3. Autoriza la instalación desde orígenes desconocidos si Android lo solicita.
4. Instala el APK sobre una versión anterior compatible.

También se puede actualizar mediante ADB:

```powershell
adb install -r QUIPU-1.0.9.apk
```

No es necesario desinstalar QUIPU ni borrar sus datos.

## Limitaciones conocidas

- Los recordatorios no admiten recurrencia.
- No existe sincronización entre dispositivos ni copia de seguridad en la nube.
- La interfaz está disponible en español.
- La búsqueda utiliza coincidencia de texto; no hay índice FTS.
- Las alarmas exactas dependen del permiso del sistema y del fabricante. Sin ese
  permiso, Android puede retrasar los avisos.
- Las notas eliminadas definitivamente conservan sus recordatorios, pero los
  desvinculan.
